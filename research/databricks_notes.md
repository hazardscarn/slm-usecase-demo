# Databricks GPU pricing notes (accessed 2026-11-08)

## Verified from official pages
- Model Serving GPU DBU/hour (https://www.databricks.com/product/pricing/model-serving): T4x1 10.48; A10G x1 20.00 / x4 112.00 / x8 290.80; L40S x1 44.86; A100-40GB x8 538.40; A100-80GB x8 628.00; RTX PRO 6000 x1 80.00; H100 x1 100.00 / x8 800.00. Pay as you go, 14-day trial, committed-use discounts via sales.
- Foundation Model Serving DBU rates (https://www.databricks.com/product/pricing/foundation-model-serving), pay-per-token DBU per 1M tokens (input/output): Llama 3.1 8B 2.143/6.429; Gemma 3 12B 2.143/7.143; GPT-OSS-20B 1.000/4.286; GPT-OSS-120B 2.143/8.571; Llama 3.3 70B and Llama 4 Maverick 7.143/21.429; Qwen 3 80B 2.143/17.143; Qwen 3.5 122B 3.143/31.429. Price = DBU rate x $/DBU (page example uses $0.07/DBU, AWS US East: 7.143 DBU -> $0.50).
- Provisioned Throughput on-demand (DBU/hour "per 50 model units", per-minute billing): Llama 3.2 1B 42.857; 3B 46.429; Llama 3.1 8B 53.571; GPT-OSS-20B 53.571; Gemma 3 12B 71.429; GPT-OSS-120B 71.429; Llama 3.3 70B / Maverick 85.714; Qwen 3 80B 104.762. 1-month/3-month reservations exist only for newer big models (142.857 / 128.571 DBU/h). Throughput per model unit is model/request dependent (use their GenAI calculator) -> tokens/s per unit NOT verified.
- Batch inference (ai_query) is billed per hour at the same DBU/h as PT on-demand (e.g. Llama 3.1 8B 53.571, GPT-OSS-120B 71.429, Gemma 3 12B 71.429).
- Region/cloud availability of models on GCP-hosted Databricks is not verified (page says "displayed pricing does not guarantee availability").
- Foundation Model Fine-tuning (Mosaic AI Model Training): **end of life**, databricks_genai package and UI no longer available (https://docs.databricks.com/aws/en/large-language-models/foundation-model-training/index.html). Last published examples (https://www.databricks.com/product/pricing/foundation-model-training), $0.65/DBU US East: Llama 3.1 8B 100 DBU/10M words ($65), 4,400 DBU/500M words ($2,860); Llama 3.2 3B 2,750 DBU/500M; Llama 3.3 70B 11,000 DBU/500M. Recommended 1-4 epochs. Gemma/Qwen/MoE were not offered.
- Replacement: AI Runtime (serverless GPU; A10, 1xH100, 8xH100, 8xB300 waitlist). The pricing page metadata lists clouds = AWS and Azure ONLY; docs.databricks.com/gcp has no AI Runtime page -> **not available on Databricks-on-GCP**. Docs (docs.databricks.com/aws/en/machine-learning/ai-runtime/overview, updated Nov 5 2026).
- Classic GPU clusters on GCP supported instance types (official, https://docs.databricks.com/gcp/en/compute/gpu): a3-highgpu-8g (8xH100), a2-ultragpu-1/2/4/8g (A100-80GB), a2-highgpu-1/2/4/8g + a2-megagpu-16g (A100-40GB), g2-standard-4/8/12/16/24/32/48/96 (L4). No H200/B200/G4 on GCP classic.

## Take-aways for the use case
- Hosting 8B/12B/gpt-oss open models: Databricks pay-per-token (e.g. Llama 3.1 8B $0.15 in / $0.45 out per M at $0.07/DBU; GPT-OSS-20B $0.07/$0.30; GPT-OSS-120B $0.15/$0.60; Gemma 3 12B $0.15/$0.50) vs Vertex MaaS (Gemma 4 26B $0.15/$0.60 official; gpt-oss-120b $0.09/$0.36 third-party).
- Fine-tuned custom models need a GPU endpoint (provisioned throughput or serving endpoint). Custom LoRA'd 8B on 1xA10G = 20 DBU/h = $1.40/h vs g2-standard-8 L4 on GCE $0.85/h.
- Fine-tuning on Databricks-on-GCP = classic GPU cluster (a2/a3/g2) with DBU surcharge, not AI Runtime.
